Settings separates global preferences from configuration that belongs to the
current collection.

## Open Settings

Press <kbd>F4</kbd> from any Noodle workspace to open Settings. Alternatively,
press <kbd>Ctrl</kbd>+<kbd>P</kbd>, search for **Open Settings**, and press
<kbd>Enter</kbd>. Settings opens on the global **Appearance** section; use the
scope switcher to reach settings for the active collection.

The command palette also lists every application and collection Settings
category, so searches such as **Keyboard**, **Proxy**, or **Certificates** open
that category directly.

## Global settings

Global settings apply wherever you use Noodle. They are stored in
`~/.config/noodle/config.yml`.

### Appearance

Choose a theme and the default stacked or side-by-side layout. See
[Themes](/docs/reference/theming/) for the available themes.

### Behavior

Choose whether undo-all asks for confirmation and select a detected external
editor. The command palette uses that editor for **Open Collection in Editor**
and **Open Settings in Editor**. Noodle detects Zed, Visual Studio Code, Sublime
Text, Cursor, Windsurf, and VSCodium when installed.

### Collections

Manage registered collection directories and their order. Noodle opens the
first valid registered collection when no collection path is supplied, and the
collection switcher updates this list as you work.

### Keyboard shortcuts

Customize supported shortcuts from the Keyboard section. Fixed navigation and
editing keys cannot be reassigned. See [Keybindings](/docs/reference/keybindings/)
for every available binding ID and default.

### Proxy policy

See [Proxies and TLS](/docs/guides/proxies-and-tls/#proxy-policy) for setup, supported fields, and connection checks.

## Collection settings

Collection settings apply only to the active collection and are saved in its
`settings.yml` file.

### General

Set a display name and description for the collection. You can also set
`timeline_max_entries`, which retains 50 responses per request by default.
Lowering the value removes older entries; set it to `0` to disable response
history for the collection.

The **Cookie jar** toggle is enabled by default. When enabled, Noodle captures
`Set-Cookie` headers and sends matching cookies on later requests. Turning it
off prevents both sending and capturing jar cookies for the collection. Use the
request pane's **Send Cookies** control when only one request should omit
outgoing jar cookies. See [Cookies](/docs/guides/cookies/) to inspect and manage the jar.

### Collection proxy

See [Proxies and TLS](/docs/guides/proxies-and-tls/#collection-proxy) for setup, supported fields, and connection checks.

### TLS and mutual TLS

See [Proxies and TLS](/docs/guides/proxies-and-tls/#tls-and-mutual-tls) for setup, supported fields, and connection checks.

### Proxy precedence

See [Proxies and TLS](/docs/guides/proxies-and-tls/#proxy-precedence) for setup, supported fields, and connection checks.

## File references

The Settings workspace edits the same files you can manage directly:

- [Configuration](/docs/reference/configuration/) documents global `config.yml`.
- [Collection YAML](/docs/reference/collection-format/#collection-settings-settingsyml)
  documents collection `settings.yml`.

The command palette's **Open Settings in Editor** action opens the application
settings directory in the selected external editor.

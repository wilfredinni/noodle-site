---
title: Insomnia Import
description: Import Insomnia v4 and v5 JSON exports as Noodle collections
---

Import an Insomnia JSON export:

```bash
noodle import ./insomnia-export.json -i insomnia
noodle import ./export.json -i insomnia -o ./collections
```

Noodle supports Insomnia export formats 4 and 5. It imports supported
workspaces, request groups, requests, environments, headers, parameters, body
types, and auth. Cyclic request groups are skipped.

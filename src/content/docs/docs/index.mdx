Noodle keeps requests in YAML files and gives you a terminal workspace to edit,
send, and inspect them. Start with the interactive client, then run the same
files from the CLI when you need repeatable checks.

## Start with one request

1. [Install Noodle](/docs/getting-started/installation/).
2. [Create and send your first request](/docs/getting-started/quick-start/).
3. [Learn the layout and navigation](/docs/reference/layout/).

## Settle into the workspace

Use [Core concepts](/docs/getting-started/concepts/) to understand collections,
requests, environments, and focus. [Find requests](/docs/guides/using-the-sidebar/)
explains the collection tree and search. [Create and send requests](/docs/guides/using-the-request-pane/)
covers headers, parameters, bodies, cURL import, and generated client code.

## Bring existing work with you

[Import](/docs/import/import/) collections from OpenAPI, Swagger, Postman, or
Insomnia. [Export](/docs/import/export/) as OpenAPI or Postman when another tool
needs the files. [AI agent skills](/docs/guides/ai-agent-skills/) lets a coding
agent help maintain the same collections.

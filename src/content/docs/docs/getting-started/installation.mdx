title: Installation
description: Install Noodle on macOS or Linux, confirm the binary works, and keep it current.
---

Install Noodle with the script for the shortest path, Homebrew when you prefer
package-managed updates, or source when you need a platform without a prebuilt
binary.

## Quick install

```bash
curl -LsSf https://noodlerest.dev/install.sh | sh
```

Detects your OS and architecture, downloads the latest binary, and drops it
at `~/.local/bin/noodle`.

If `~/.local/bin` isn't on your `$PATH`, the script will let you know: just
add this to your shell config (`~/.zshrc`, `~/.bashrc`, etc.):

```bash
export PATH="$HOME/.local/bin:$PATH"
```

**Custom install location?** Set `NOODLE_INSTALL_DIR`:

```bash
NOODLE_INSTALL_DIR=/usr/local/bin curl -LsSf ... | sh
```

**Need a specific version?** Pin it with `NOODLE_VERSION`:

```bash
NOODLE_VERSION=v0.6.0 curl -LsSf https://noodlerest.dev/install.sh | sh
```

## Homebrew

```bash
brew tap wilfredinni/noodle
brew trust wilfredinni/noodle
brew install noodle
```

## From source

Requires [Bun](https://bun.sh).

```bash
git clone https://github.com/wilfredinni/noodle
cd noodle
bun install
bun run build:bin
```

The binary lands at `./noodle`. On macOS, the build ad-hoc signs and verifies
it before running the compiled scripting smoke check. Move it somewhere on
your `$PATH`.

## Did it work?

```bash
noodle --help
```

You should see the CLI usage output. To launch the TUI:

```bash
noodle
```

## Supported platforms

Prebuilt binaries for these combos: others need to build from source.

| Platform | Architecture | Binary |
| -------- | ------------ | ------ |
| macOS    | arm64        | ✅     |
| macOS    | x86_64       | ✅     |
| Linux    | x86_64       | ✅     |
| Linux    | arm64        | ✅     |

Both Apple Silicon and Intel Macs have prebuilt binaries. macOS release
artifacts are ad-hoc signed and verified before publication, including checks
of the downloaded artifact's checksum, signature, version, and script sandbox.

## Updating

```bash
noodle update
```

Homebrew installs run `brew upgrade noodle`. Standalone binaries read Noodle's
update manifest, download the matching release, and verify its SHA-256 checksum
before replacement. Update checks cache release metadata for one hour; pass
`--force` to bypass that cache, or `--json` for scripted use.

The TUI performs the same check when it starts and installs an available update
automatically. Progress appears in the header and beside the current version in
**About and Updates**, which is available from the command palette.

## AI Agent Skills

Install the `noodle-use` skill to teach your AI coding agent how to
create, organize, and audit noodle collections:

```bash
noodle agent install
```

Noodle stores one managed copy under `~/.agents/skills/noodle-use`, links
detected Claude, Cursor, Codex, and OpenCode installations to it, and keeps an
existing managed installation synchronized when Noodle updates. For other
clients, use the skills CLI fallback:

```bash
npx skills add wilfredinni/noodle --skill noodle-use -g
```

After installing, ask your agent to scaffold a collection, audit your
requests for security issues, or convert an Insomnia export.
